## What is measured (the ledger and the predictor of the seventh check are not changed)
1. **The name prior pooled.** The same leave-one-game-out prior as before (the direction an action's name made in the other games, used when at least 90 percent of at least 4 levels agree), but taken from the levels of **all four arms** of the other three games. A game never reads its own levels for it. Counted for each of ACTION1 to ACTION4: levels in which the action made a step, levels in which a prior existed, levels in which it named the direction made. The tiers (`nm`, `all7`, `best`) are then read as in the seventh check.
2. **The retire rule.** In the `all7` way, a law (law tier) that has been wrong by a different step `retire` times in a level is not used again in that level for that action: its move is left to the model and counted as not predicted. `retire` is 1 and 2, and 1 also in the `best` way. For each the page counts: right moves lost, wrong moves avoided, the share right among the predicted, and the **break-even ratio** (right moves lost divided by wrong moves avoided): what one wrong move would have to cost, in right ones, for the rule to pay. No cost is assumed here.
3. **The six clears.** For each level the saved runs cleared, and for every level of 20 or more recorded moves they did not clear, the screen just before the end of the level against its first screen: whether a symbol that is not a ticking strip has a different number of cells (the cells the strip changed in that level are left out of both screens first, so a strip turning into background colour does not count as a change of the board), and whether the clearing move was made with an action that already had a law of at least 3 tries in that level. A description for the goal question (concept-map row 177), no more.

Nine ways run on the same moves: `full`, `once`, `all6`, `nm`, `all7`, `best`, `all7_r1`, `all7_r2`, `best_r1`. Each is run twice: with the prior taken per arm (as in the seventh check) and pooled. With the prior per arm and no retire rule the counters are the seventh check's, counter for counter (a test holds that on the invented worlds; line 2 holds it on the real moves). The same saved arms (K, A, B and C, 960 moves), replayed into fresh copies of the games. The code is `python/axi/experiments/foresee8.py` (it reads the ledger as it is and adds no line to it), the notebook `python/colab/axi_foresee_check_8.ipynb`, the terminal runner `python/colab/run_foresee_check_8.py`.
