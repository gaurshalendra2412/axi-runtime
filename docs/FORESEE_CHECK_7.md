## What is measured (the ledger and the predictor of the sixth check are not changed)
1. **A first try, answered from the name (`nm`, `nc`).** For an action never tried in this level: the direction is the direction that name had in the **other games** (a game never reads its own levels for it; only when at least 90 percent of at least 4 levels of the other games agree), the length is the one length of the steps this level has already shown (tier `nm`), or else the length of the latest earlier level of the same game with the mover's symbol it had (tier `nc`). If the steps seen disagree in length, or the name has no agreed direction, nothing is predicted. Order when several apply: the carried relation, then the name, then the rotation set.
2. **The arrangement class.** Each level in which all four of ACTION1 to ACTION4 made a step of one length is counted into one of the 6 classes.
3. **The screen memory, strip found online.** At every move the strip that ticks is found from the moves before (`Ledger.tick_cells`: the cells it has already changed), and every earlier screen and this one are read with those cells left out; the same action on the same screen is a repeat. A strip that is used up has one cell about to change that has not changed yet, so that mask leaks one cell at every move; it is therefore also counted with a second mask, `scx`: the cells already changed **and** every cell of the strip's symbol on the current screen. Both are counted side by side (`scr` and `scx`); the reading lines 7 to 9 are read on `scx`. It is counted how often the same action on the same screen repeats, how often an earlier "no change" is "no change" again, and how often the screen after is exactly the one it ended on last time. The moves that no other tier predicted are given that earlier outcome and scored by exactness of the whole screen after (a stricter yardstick than the one the tiers use); where a tier did predict, the two are counted side by side. A strip that grows leaks its new cell under both masks. The memory changes no prediction. A strip is found only after it has ticked in enough moves (`Ledger.ticks`), so the first moves of a level are never repeats.
4. **The retire question.** After a law-tier prediction for an action has been wrong by a different step, how right are the later law-tier predictions for that action, against before the first failure? It is a count; no law is taken away.
5. **The edge.** When the step would leave the board and the piece is predicted to stay, did it stay (a block) or move (which would include a wrap)?
6. **The best way.** All of it together with the floor colours and the mover as a group deleted (the Delete Test's two gains).

Six ways run on the same moves: `full` (must give the third check's 603 right of 729), `once` (the fifth check's 663 of 797), `all6` (the sixth check's `all`, 672 of 809), `nm`, `all7` (once, rot, rel and nm, with the screen memory), `best`. The same saved arms (K, A, B and C, 960 moves), replayed into fresh copies of the games. No model, no cost. The code is `python/axi/experiments/foresee7.py` (it reads the ledger as it is and adds no line to it), the notebook `python/colab/axi_foresee_check_7.ipynb`, the terminal runner `python/colab/run_foresee_check_7.py`.

On the invented worlds the new parts predict almost nothing (there the four actions are tried at the start). On small worlds built for the purpose with steps of three cells, `nm` predicts the first try of D, L and R from U's length and the name's direction; with no step seen it uses the carried length; with names that disagree in length it predicts nothing.
